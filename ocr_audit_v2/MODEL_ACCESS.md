# تشغيل النموذج في العرض الأكاديمي

- الموقع: https://abade1990-audit-review-private.hf.space/
- كلمة مرور بدء النموذج: `abdullah2030` — كلمة عرض منشورة بإذن صاحب المشروع، وليست كلمة حساب أو مفتاح استضافة.
- فتح الموقع لا يشغّل GPU. يُطلب إدخال الكلمة عند تشغيل المبدّل، ويُعاد التحقق داخل `model_service.start` قبل تغيير الحالة أو إنشاء عملية أو الاتصال بالمزوّد. الإيقاف لا يتطلب كلمة مرور.
- خمس محاولات خاطئة تقفل البدء عشر دقائق. يحتفظ الخادم ببصمة مملّحة، وتبقى حالة القفل خارج الملفات التي يقدمها Gradio.

## الاستضافة

واجهة Hugging Face تعمل على CPU. بعد التحقق من كلمة المرور، تطلب خدمة التشغيل مورداً واحداً من RunPod للنموذج المعتمد. لا تحتاج هذه البنية إلى جهاز صاحب المشروع. تتطلب رصيداً ومورداً متاحاً. في 27 أكتوبر 2026 شُغّل النموذج بكلمة المرور عبر واجهة API لموقع Hugging Face، وقرئت عينة مصورة اصطناعية من ثلاث صفحات وصدر تقرير Excel، مع بقاء خدمة النموذج المحلية مطفأة. ثم أُوقف المورد وتحقق من عدم وجود GPU يعمل. لم يُختبر جهاز الدكتور نفسه.

مفتاح RunPod محفوظ في Secret باسم `RUNPOD_API_KEY` داخل Space بموافقة صاحب الحساب. لا يُرفع المفتاح إلى المستودع أو GPU. مراقب المورد يستخدم هوية وصلاحية المورد التي يحقنها المزوّد، ويتحقق منها قبل تثبيت النموذج. مراقب آخر يعمل في خادم الواجهة.

سقف جلسة التشغيل 2 دولار، والحد الزمني 180 دقيقة أو المدة الأقصر التي يسمح بها السقف مع احتياطي 10%. السعر المقبول لا يتجاوز 1.09 دولار/ساعة. يُفحص الرصيد قبل الحجز؛ عند فشل تأكيد الإيقاف تبقى هوية المورد محفوظة لإعادة المحاولة.

## التحقق المنفذ دون GPU

- رفض كلمة فارغة وخاطئة على مساري API الفعليين، محلياً وعلى موقع Hugging Face، مع بقاء النموذج مطفأً.
- اختبار كلمة صحيحة في بيئة اختبار مع استبدال التشغيل بمحاكاة؛ لا طلب مورد مدفوع.
- اختبار قفل المحاولات، وغياب الإعدادات، وتلف حالة المصادقة، وفحص الرصيد قبل الحجز، وحفظ هوية المورد إذا تعذر إيقافه.
- تحقق تطابق SHA-256 لملفات النشر وأرشيف الأوزان. الحسابات وقوالب Excel والأوزان وإعدادات القراءة لم تتغير.

تُنشئ `prepare_space_update.py` حزمة رفع محددة الملفات دون أسرار أو بيانات مستندات. تُحفظ أوزان النموذج على Hugging Face؛ لا تُضاف إلى GitHub.

## تجربة التصميم المختلف 842 — تاريخ محفوظ، ليست اختبار القبول الرسمي

- عُولج نقص ملف موجّه القراءة المعتمد في النشر، وخطأ توافق f-string مع Python 3.11؛ لم تتغير الأوزان أو قواعد الحساب أو القوالب. أضيف تحقق ملفات التشغيل قبل حجز المورد، وسجل لأخطاء عامل الفحص.
- المهمة `20261027-033101-26a69f`: بدأت 03:31:01 UTC وانتهت إلى المراجعة 03:33:19 UTC. استخراج العينة استغرق 138 ثانية بعد تجهيز النموذج.
- قرأ السند `STO0008420001` والتعميد `PON0008420001` ومرجع الفاتورة `5270000001`. القيم المطبوعة المستخرجة: الصافي 339.00، العمولة 13.56، الضريبة 49.92، الإجمالي 402.48.
- ظهرت ست حالات مراجعة؛ لم تكتمل قراءة البنود وربط الفاتورة. صفحة التقرير تعرض أصفاراً محسوبة عند غياب البنود، ولا يجوز اعتبارها مبالغ مالية مثبتة. لم يُعدّل منطق الحساب في إصلاح النشر، وتبقى هذه نقطة تتطلب إصلاحاً منفصلاً قبل الاعتماد المالي.
- هذه نتيجة تحقق تشغيل واستخراج جزئي، وليست اجتيازاً للتدقيق الكامل أو قياس دقة أو اعتماداً للمخرجات. العينة بلا عقد وليست المنافسة كاملة.
- تأكد الإيقاف: صفر GPU يعمل. جميع المفاتيح بقيت خارج الملفات المنشورة.
